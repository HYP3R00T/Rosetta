# Hide text in Obsidian

Sometimes, we might want to hide some text like answer. For such situation, use the following. This is called "Callout" in obsidian. In other tools it's also called "Admonition" 

```markdown
> [!tip]- How are you?
> I'm good
```

Example:

> [!tip]- How are you?
> I'm good
