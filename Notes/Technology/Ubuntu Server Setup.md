# Ubuntu Server Setup

- Download and prepare bootable USB (Ventoy is recommended)
- Boot into the USB
- Ensure you choose a network when prompted
- Update to new installer
- Config the partition as you wish
- Install OpenSSH server
- Do NOT add any server snaps when prompted as we will install them later

---

- [Ventoy](https://github.com/ventoy/Ventoy)
- [Ubuntu server](https://ubuntu.com/download/server)
