# Configuring pyproject.toml

If `uv` is used to create the project, we will have the following content in `pyproject.toml`.

```toml
[project]
name = "cybershell"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.12"
dependencies = []
```
