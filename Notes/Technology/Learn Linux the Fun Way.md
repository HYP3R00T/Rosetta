# Learn Linux the Fun Way

Whenever we want to learn something new, we typically have a few standard options: reading the documentation, watching a YouTube playlist, taking certified courses, or reading books. While these can be excellent sources of learning, they’re not always the most enjoyable.

There’s nothing wrong with these methods, but they can sometimes feel a bit boring. If you want to learn Linux and have some fun along the way, check out the following resources.

- [Linux Upskill Challenge](https://linuxupskillchallenge.org/)
- [OverTheWire - Wargames](https://overthewire.org/wargames/) [Recommended]
