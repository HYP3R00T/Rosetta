# Localhost

According to IANA, IP address block `127.0.0.0/8` is allocated for Loopback. So, when we enter localhost with some port (presuming some app or server is running on that port), we access `127.0.0.1`. This can be thought of as the smallest using of network. Basically, if there is any machine, it will have a Loopback address.
